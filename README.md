# Aplikasi Kriptografi - Tugas Kelompok

Aplikasi web berbasis Python menggunakan **Streamlit** untuk melakukan enkripsi dan dekripsi menggunakan berbagai algoritma kriptografi klasik, modern, serta super enkripsi[cite: 1].

## Fitur Menu Aplikasi
1. **Algoritma Klasik 1** (Contoh: Vigenere / Caesar Cipher)[cite: 1]
2. **Algoritma Klasik 2** (Contoh: Playfair / Hill Cipher)[cite: 1]
3. **Algoritma Modern 1** (Contoh: AES / DES)[cite: 1]
4. **Algoritma Modern 2** (Contoh: RSA)[cite: 1]
5. **Super Enkripsi** (Gabungan berurutan dari 4 algoritma di atas)[cite: 1]
* *Fitur Tambahan:* Halaman visualisasi proses tahapan enkripsi dan dekripsi[cite: 1].
